### `> featured: ReconClaw`
#### [ReconClaw v4.0](https://github.com/Pireburak/ReconClaw)
**Async network discovery, banner grabbing, and AI-assisted risk analysis.**
Yetkili keşif ve pentest iş akışı için tasarlanmış bir siber güvenlik aracı: hızlı tarama, servis istihbaratı ve risk skoru tek yerde.
| Capability | What it does |
| --- | --- |
| Async socket engine | Python `asyncio` ile çok sayıda portu UI'yı kilitlemeden tarar |
| Banner / version intel | Açık servislerden sürüm bilgisi toplar |
| Risk engine | Sürümlere göre olası CVE'leri eşler ve risk skoru üretir |
| OSINT footprint | IP-API ile loc, ASN / ISP ve veri merkezi bağlamı |
| Matrix UI | Tek dosyada gömülü terminal-tarzı arayüz |
