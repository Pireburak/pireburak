# Fontlar

SVG görsellerine gömülen fontlar, Türkçe karakterleri kapsayacak şekilde alt kümelenmiş (subset) WOFF2 dosyalarıdır.
Hepsi [SIL Open Font License 1.1](https://openfontlicense.org) ile lisanslıdır ve Google Fonts üzerinden alınmıştır.

| Dosya | Font | Tasarımcı |
| --- | --- | --- |
| `cinzel-*.woff2` | Cinzel | Natanael Gama |
| `greatvibes.woff2` | Great Vibes | Robert Leuschke (TypeSETit) |
| `jbm-*.woff2` | JetBrains Mono | JetBrains |
